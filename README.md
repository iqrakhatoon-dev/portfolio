# Iqra Khatoon — Developer Portfolio

> *"Building the Web, one component at a time."*

A clean, minimal personal portfolio built to showcase my journey as a Full Stack Developer — featuring my projects, skills, and a way to get in touch.

---

## ✨ Features

- **Hero Section** — Personal intro with name, title, and call-to-action buttons
- **About Section** — Brief bio with tech stack skill cards
- **Featured Projects** — 4 highlighted projects with tags, GitHub & Live Demo links
- **Tools & Skills** — Categorized frontend, backend, and DevOps stack
- **Contact Section** — Inquiry form with social links

---

## 🛠️ Built With

- **React** — Component-based UI
- **Vite** — Fast dev environment & bundler
- **CSS / Tailwind CSS** — Styling and layout
- **GSAP** — For animation

---

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/iqrakhatoon-dev/portfolio

# Navigate into the project
cd portfolio

# Install dependencies
npm install

# Start dev server
npm run dev
```
